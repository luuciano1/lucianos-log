    What is it
    Find art

    Find art opens an image search in a new tab. Save the one you like, then choose it here. On a computer you can also paste or drop an image.

    Unrated

    posters and film details

    This looks up each film without a poster on The Movie Database, then fills in the poster, director, genre and release date. It never overwrites anything you've already filled in.

    Free from themoviedb.org: Settings, then API, then request a developer key. Paste the long "API Read Access Token". It's saved in this browser only and sent only to TMDB.

    publish

    Publishing saves your entries and covers to your GitHub repo. Visitors see them after GitHub rebuilds the site, usually 1 to 2 minutes.

    Use a fine-grained token limited to this repository, with Contents set to Read and write. It is saved in this browser only and sent only to GitHub.
